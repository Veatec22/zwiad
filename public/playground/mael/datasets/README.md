# M?L sample datasets

All CSV files in this folder are synthetic demo datasets generated for this repository. They are not real customer, financial, medical, or credit records.

- `customer_churn.csv`: synthetic balanced binary churn example.
- `wine_quality.csv`: synthetic multiclass wine quality example inspired by common wine-quality feature names, not copied from UCI.
- `house_prices.csv`: synthetic regression housing-price example.
- `fraud_detection_mini.csv`: synthetic imbalanced binary fraud example.
- `loan_approvals_trap.csv`: synthetic leakage demonstration. It intentionally includes a unique ID and a target-leaking score column.
